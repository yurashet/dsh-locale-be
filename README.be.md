# dsh-locale-be

Беларуская лакалізацыя вэб-інтэрфейсу [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness).

[Read in English](README.md)

- **60 прастораў імён, 2713 радкоў** — чат, налады, мадэлі, плагіны, skills, MCP, сесіі, дыягностыка, гарычыя клавішы.
- Плагін толькі рэгіструе мову праз публічны API `ctx.locale`. Без сеткі, крэдаў, тэлеметрыі і змен у кодзе DSH.
- Праверана на DSH `0.2.1-rc.2`, Windows 11, Node.js 22.

## Усталяванне

Патрэбны DSH `0.2.1-rc.2` або навейшы і `pnpm` (яго выкарыстоўвае `dsh plugin`).

```sh
dsh plugin --profile web add github:yurashet/dsh-locale-be
dsh web
```

Бандл дадае плагін і па змаўчанні выбірае беларускую мову. Калі інтэрфейс застаўся на іншай мове, адкрыйце **Налады → Агульныя → Мова** і абярыце **Беларуская**.

Для фіксаванай версіі:

```sh
dsh plugin --profile web add github:yurashet/dsh-locale-be#<40-сімвальны-хэш-каміта>
```

З лакальнага клона:

```sh
git clone https://github.com/yurashet/dsh-locale-be.git
dsh plugin --profile web add ./dsh-locale-be
```

## Што перакладзена

Чат і размовы, налады, працоўная прастора, агенты і каманды, skills і MCP, гісторыя і дыягностыка, кароткія каманды.

Тэхнічныя радкі — URL, назвы пратаколаў, коды памылак і дынамічныя назвы мадэляў — наўмысна застаюцца лацінкай.

## Вядомыя абмежаванні

- Некаторыя дынамічныя назвы мадэляў могуць заставацца па-англійску, пакуль DSH не аддасць іх як ключы лакалізацыі.
- DSH `0.2.x` можа перазапісаць `cordis.patch.yml` пры захаванні **Налады → Мадэлі**. Пасля захавання праверце, што запісы `be-locale` і `locale.preference: be` на месцы.
- Пераклад імкнецца да жывой літаратурнай беларускай мовы, а не да калькі. Прапановы па тэрміналогіі вітаюцца.

## Распрацоўка

Залежнасцей няма.

```sh
npm test          # праверыць слоўнік, маніфест, patch і згенераваны бандл
npm run build     # перагенераваць lib/client.js з translations.be.json
npm run build:check
```

Каб прапанаваць праўку:

1. Змяніце `translations.be.json`.
2. Не чапайце плейсхолдары `{name}`, `{count}`, `{message}`.
3. Захоўвайце пары множнага ліку (`.one`, `.other`).
4. Выканайце `npm test`.
5. Адкрыйце pull request.

## Бяспека

Плагін працуе толькі ў браўзеры: рэгіструе мову і слоўнікі праз публічны сэрвіс лакалізацыі, не чытае файлы, не ходзіць у сетку і не мае доступу да крэдаў. Як і любы плагін DSH, стаўце яго з даверанай крыніцы; для прайгравальнасці фіксуйце каміт.
