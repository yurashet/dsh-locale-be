# DSH plugin market

This directory is a format-1 plugin market index for DeepSeek Harness.

Market URL:

```text
https://yurashet.github.io/dsh-locale-be/index.json
```

## Use it

1. Open **Plugins** in DSH.
2. Select **More** beside **Experimental plugins** and switch on **Custom plugin markets**.
3. Open **Discover**, choose **Add index source**, and paste the market URL.
4. Select the **Belarusian** card and install `0.1.0`.

The index lists a commit-pinned Git source, so the installer fetches exactly the released revision.

## Files

| File | Purpose |
|---|---|
| `index.json` | Market index (format 1) |
